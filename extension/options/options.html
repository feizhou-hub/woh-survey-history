WOH Survey → Google Sheets

Connect this extension to a Google Apps Script web app that writes rows into your spreadsheet.

  1. Create a Google Sheet
  2. Open Extensions → Apps Script and paste apps-script/Code.gs
  3. Set the same SECRET in Apps Script and below
  4. Deploy → New deployment → Web app (Execute as: Me, Access: Anyone)
  5. Paste the Web App URL below
